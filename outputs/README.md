# Outputs — where the work lands

Each agent drops its finished work in its own tray. One episode keeps the same
date-and-topic name through all four trays.

| Folder | Filled by | What's inside |
|---|---|---|
| `01-topic-briefs/` | Trend Scout | 3 topic options per run, with sources and scripture |
| `02-scripts/` | Scriptwriter | Full 20–30 minute scripts with visual cues and Short markers |
| `03-upload-kits/` | Clip & Package Producer | Titles, thumbnail concept, description, tags and Shorts |
| `04-approved/` | Kingdom Reviewer | **Finished episodes, ready for you to record and upload** |

Only `04-approved/` is ready for the public, and only after you look it over.
